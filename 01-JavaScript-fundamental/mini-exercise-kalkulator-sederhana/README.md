# Mini Exercise: Kalkulator Sederhana

Latihan logika dasar JavaScript untuk membuat kalkulator aritmatika sederhana dengan percabangan kondisi.

---

## 📌 Apa yang Dikerjakan

- Membuat fungsi `hitung(a, b, operasi)` untuk memproses operasi:
  - `tambah` (Penjumlahan)
  - `kurang` (Pengurangan)
  - `kali` (Perkalian)
  - `bagi` (Pembagian, dengan penanganan pembagian angka 0)
- Menampilkan output hasil perhitungan ke konsol terminal.

---

## 🚀 Cara Menjalankan

1. Masuk ke direktori:
   ```bash
   cd 01-JavaScript-fundamental/mini-exercise-kalkulator-sederhana
   ```
2. Jalankan file:
   ```bash
   node index.js
   ```

---

## 💡 Catatan & Dependensi
- Berjalan langsung menggunakan **Node.js** tanpa dependensi eksternal.
